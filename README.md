# Physical Progression

[简体中文](README_zh-CN.md)

Physical Progression is a Minecraft mod that develops your character’s physical abilities through everyday activity. Walk, run, swim, climb and use tools to improve your body through exertion and recovery, without allocating skill points.

## Features

- **Physical development:** improve cardio, lung capacity, leg and arm strength and endurance, grip, core strength, explosiveness, mobility, recovery and climbing ability.
- **Stamina and recovery:** manage separate stamina resources for the whole body, legs and each arm. Walking allows recovery; standing still restores stamina faster.
- **Wall climbing:** face a nearby wall and hold the jump key to climb. Climbing and hanging consume stamina, and exhaustion causes you to let go.
- **Body overview:** press **C** to view your own player model, current resources and long-term abilities.
- **Training history:** inspect recent sessions, including duration, intensity, resource consumption and growth results.
- **Adjustable interface:** customize HUD, text, training notification and menu sizes. Compact resource indicators sit at the left center by default, with a bottom-left option. Recovered resources fade out, and low stamina displays a percentage.
- **Configurable progression:** adjust activity costs, recovery and growth through external configuration files.

## Requirements and installation

For **Minecraft Java Edition 1.21.1**, **NeoForge 21.1.250 or later within Minecraft 1.21.1**, and **Java 21**.

Install the **same mod JAR on both the client and server**. For single-player, place it in your local instance’s `mods` folder. For multiplayer, every player and the server need the mod.

Gameplay settings are generated in `config/physical_progression-server.toml`, or the world’s `serverconfig` directory when per-world configuration is enabled. Local interface settings use `physical_progression-client.toml`. Close the game or stop the server before editing configuration files.
