# Physical Progression

[English](README.md)

Physical Progression 是一个通过日常活动提升角色身体能力的 Minecraft 模组。通过行走、跑步、游泳、攀爬和使用工具，让身体在运动与恢复中逐渐变强，无需分配技能点。

## 功能

- **身体成长：**提升心肺、肺活量、腿部与双臂力量和耐力、握力、核心力量、爆发力、灵活性、恢复能力和攀爬能力。
- **耐力与恢复：**管理全身、腿部和左右臂各自独立的耐力资源。行走时可以恢复体力，静止时恢复更快。
- **贴墙攀爬：**面对附近的墙面，按住跳跃键即可攀爬。攀爬和悬挂都会消耗体力，力竭后会松手。
- **身体总览：**按 **C** 查看玩家自身模型、当前资源和长期身体能力。
- **训练记录：**查看近期训练，包括时长、强度、资源消耗和成长结果。
- **界面调整：**自定义 HUD、文字、训练提示和菜单大小。紧凑资源提示默认显示在左侧中部，也可切换到左下角。资源恢复后淡出，低耐力时显示百分比。
- **成长配置：**通过外部配置文件调整活动消耗、恢复和成长数值。
