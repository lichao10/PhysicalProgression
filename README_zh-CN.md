# Physical Progression

[English](README.md)

Physical Progression 是 Minecraft 的身体成长模组。通过行走、跑步、游泳、攀爬和使用工具，让角色在运动与恢复中逐渐变强，无需分配技能点。

## 主要功能

- **身体成长：**逐步改善心肺、肺活量、腿部与双臂力量和耐力、握力、核心力量、爆发力、灵活性、恢复能力和攀爬能力。
- **耐力与恢复：**全身、腿部和左右臂拥有独立耐力资源；正常行走可以恢复体力，静止时恢复更快。
- **贴墙攀爬：**面对并贴近墙面，按住跳跃键即可攀爬。攀爬和悬挂都会消耗体力，力竭后松手下落。
- **身体菜单：**按 **C** 查看玩家自身模型、当前资源与长期身体能力。
- **训练记录：**查看近期训练，并点开每次记录查看时长、强度、资源消耗和成长结果。
- **界面设置：**可调整耐力条、文字、训练完成提示和菜单大小。紧凑资源提示默认位于左侧中部，也可切换到左下角；资源恢复后淡出，低耐力时显示百分比。
- **玩法配置：**通过游戏外的配置文件调整运动消耗、恢复速度和成长数值。

## 运行要求与安装

适用于 **Minecraft Java Edition 1.21.1**、**NeoForge 21.1.250 或适用于 Minecraft 1.21.1 的更新版本**，需要 **Java 21**。

**客户端与服务端都要安装，使用同一个 JAR 文件。** 单人游戏只需将文件放入本地实例的 `mods` 文件夹；多人游戏需要每位玩家和服务器均安装。

玩法配置自动生成在 `config/physical_progression-server.toml`，启用每世界配置时可能位于世界的 `serverconfig` 文件夹。本地界面设置使用 `physical_progression-client.toml`。修改前请退出游戏或停止服务器。
